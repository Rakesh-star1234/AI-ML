## 💻 How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/Rakesh-star1234/AI-ML.git
   ```

3. Open the project folder in VS Code.
4. Run a Python file:

   ```bash
   python filename.py
   ```

   On Windows, you can also try `py filename.py`.
